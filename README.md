# visiondeck-releases — superseded

The product is **VisionDesk**. This repository's name was misspelled and has been replaced by
**[in16guus/visiondesk-releases](https://github.com/in16guus/visiondesk-releases)**.

It stays online on purpose, for two groups that cannot be migrated:

1. **VisionDesk 1.0.0 headset app.** Its Privacy, Terms and Support links are compiled into the
   shipped binary and point at this repository's Pages site. GitHub does not redirect Pages URLs
   after a rename, so those pages are served here as redirects instead of 404s.
2. **VisionDesk Mac Host 1.0.0.** Its Sparkle feed URL points at this repository's
   `releases/latest/download/appcast.xml`. The releases here are therefore left in place, and the
   appcast keeps being updated so already-installed hosts continue to receive updates.

Nothing new is published here. Downloads, release notes and the site:
<https://in16guus.github.io/visiondesk-releases/>
