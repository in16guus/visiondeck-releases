VisionDesk has two parts: the Vision Pro app and a free Mac Host. Pair them on the same private local network, then place the displays where work feels natural.

Ready in a few minutes

You need Apple Vision Pro, an Apple silicon Mac running macOS 26.5 or later, and a local network that allows devices to reach each other.

Start in three deliberate steps.

01

Install the Vision Pro app

Get VisionDesk from the App Store. One complete spatial Mac display is ready without a subscription.

02

Install the free Mac Host

Download the signed Mac companion, move it to Applications, and open it before putting on Vision Pro.

03

Pair on your local network

Open VisionDesk in Vision Pro, choose the discovered Mac, and confirm the pairing prompt on both devices.

A normal home router works well when both devices are on the same private LAN. Guest Wi-Fi, client isolation, VPNs that capture local traffic, and enterprise Wi-Fi can prevent discovery.

Allow the one permission the Mac Host needs.

VisionDesk needs macOS Screen Recording permission to capture the displays you choose to stream. It does not upload those frames to a VisionDesk cloud service.

  1. On the Mac, open System Settings ▸ Privacy & Security ▸ Screen Recording.
  2. Enable VisionDesk. Authenticate only if macOS asks you to unlock the control.
  3. Return to VisionDesk and relaunch it once only if macOS requests it.

If VisionDesk is absent, use Grant Screen Recording… in the Mac app, then return here after macOS adds it to the list.

Choose the simplest network that stays stable.

Good default

Mac and Vision Pro connect to the same private router. Use a clean 5 GHz or 6 GHz network when available.

Better when possible

Connect the Mac to the router with Ethernet. Vision Pro remains on the router’s Wi-Fi, while the Mac has a wired backhaul.

Optional dedicated link

Use macOS Internet Sharing: Ethernet feeds the Mac, and Vision Pro joins the Wi-Fi network created by that Mac.

Do not change several quality settings at once. First test the default connection. If a direct link helps, keep it; if it makes ordinary internet access, VPNs, or other devices less convenient, switch back.

Optional: create a dedicated Wi-Fi connection from the Mac.

This configuration can reduce competition with other Wi-Fi devices. The Mac receives internet through Ethernet and shares it through its own Wi-Fi network; Vision Pro connects to that shared network. It is not required for VisionDesk and does not guarantee better results in every environment.

  1. Connect the Mac to the internet using Ethernet.
  2. Open System Settings ▸ General ▸ Sharing, turn on Internet Sharing, and choose Configure.
  3. Choose Ethernet as the source and Wi-Fi as the connection shared to devices. Give the network a unique name and a strong password.
  4. On Vision Pro, join that Wi-Fi network. Reopen VisionDesk on both devices if discovery does not immediately refresh.

Apple documents the exact controls and security options for current macOS releases in its Internet Sharing guide. Avoid this setup on a managed or enterprise network unless its administrator permits it; it may change routing, disconnect an existing Wi-Fi connection, or conflict with a VPN.

If the Mac does not appear, isolate the cause.

  1. Check that the Mac Host is open and waiting for Vision Pro.
  2. Confirm both devices are on the same private local network — not a guest network — and turn off any VPN that routes local traffic.
  3. Accept the macOS firewall prompt for VisionDesk if it appears.
  4. Reconnect once after waking the Mac or changing monitor hardware.
