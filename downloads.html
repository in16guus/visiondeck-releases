Install

  1. Open the downloaded VisionDeck-1.0.0.dmg.
  2. Drag VisionDeck into Applications and launch it from there.
  3. Grant Screen Recording when requested, then reopen VisionDeck if macOS asks.
  4. Open VisionDeck on Apple Vision Pro and select the discovered Mac.

Verify the download

Every release includes a .sha256 file. In Terminal, run shasum -a 256 VisionDeck-1.0.0.dmg and compare the result. macOS also verifies the Developer ID signature and stapled notarization ticket before launch.

Updates and rollback

The Mac app checks the signed Sparkle appcast. Use VisionDeck ▸ Check for Updates… at any time. Older releases remain visible in the repository if support asks you to test a previous compatible host.

Uninstall

Quit VisionDeck and move it from Applications to the Trash. You can remove its Screen Recording permission in System Settings. See Support for connection, permission, Gatekeeper, and update troubleshooting.
