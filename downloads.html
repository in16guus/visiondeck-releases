From download to spatial desk in four steps.

  1. 01Open the DMGDownload the signed 1.0 release and matching checksum.
  2. 02Move to ApplicationsDrag VisionDeck into Applications before opening it.
  3. 03Allow captureGrant Screen Recording when macOS requests it.
  4. 04Pair locallyOpen VisionDeck on Vision Pro and select the discovered Mac.

VisionDeck only asks for Screen Recording because the Mac Host must capture the displays you choose to stream. It does not send those frames to a VisionDeck cloud service.

One matched version on both sides.

Keep the Vision Pro app and Mac Host on the same major and minor version. That keeps pairing, workspace sync, and streaming protocol changes aligned.

VisionDeck works over the same local network. The Mac can use Wi-Fi or Ethernet as long as the router allows local devices to reach one another.

Every public build is designed to be verifiable.

Signature and notarization

Public Mac builds are distributed with a stable Developer ID signature and a stapled Apple notarization ticket. macOS validates both before first launch.

Checksum

Each release includes a .sha256 file. Run shasum -a 256 VisionDeck-1.0.0.dmg in Terminal and compare the result before installing.

Signed updates

The Mac Host checks the signed Sparkle appcast. Choose VisionDeck ▸ Check for Updates… at any time. Previous compatible releases remain in the archive for support and rollback.

Easy to remove. Nothing held in the cloud.

Quit VisionDeck and move it from Applications to the Trash. You can also remove its Screen Recording permission in System Settings ▸ Privacy & Security ▸ Screen Recording.

Pairing material is stored in the operating-system Keychain. For permission, Gatekeeper, discovery, or update problems, use the support guide.
