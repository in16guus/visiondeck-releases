Release Notes

Version history and what's new.

1.0.0 — first public release

2026-07-11

What you get

  • Up to five real virtual macOS displays streamed to Apple Vision Pro as floating RealityKit planes.
  • Three spatial layouts: flat grid, curved wrap, mixed (curved sides + flat center).
  • Per-screen drag / pinch-resize / twist / tilt / curve, with persistent settings per preset.
  • Gaze-aware bitrate — the focused screen gets full quality; peripherals run lighter.
  • Hardware HEVC encode with H.264 fallback and a low-latency local transport.
  • TLS/DTLS protection established through explicit, code-confirmed device pairing.
  • Mac audio plus direct pointer, click, scroll, and keyboard input.
  • Bonjour auto-discovery: open both apps, tap to pair.
  • Coexistence with the Apple environment already selected in visionOS.
  • Optional Custom Photo environment using an image selected by the wearer.
  • VisionDeck Free includes one complete display; VisionDeck Pro adds up to five displays, saved workspaces, and Custom Photo.
  • Native StoreKit monthly and yearly subscriptions with an eligible 14-day introductory trial, Restore Purchases, Family Sharing, and billing grace support.
  • Screen resizing up to 16× without changing the saved workspace when switching layouts.
  • Sparkle-based automatic updates on the Mac.
  • Full first-launch onboarding flow on both sides.

Distribution

  • visionOS app: free to download with optional VisionDeck Pro auto-renewable subscriptions.
  • macOS host: notarized DMG from GitHub Releases (the host uses a private macOS display API not permitted on the App Store).

Honest limitations

  • Local network only — no cloud, no internet pairing.
  • Single Mac per session.
  • Requires Screen Recording grant on macOS.
  • Apple controls the named system-environment picker; public APIs do not let VisionDeck select a specific Apple environment.
